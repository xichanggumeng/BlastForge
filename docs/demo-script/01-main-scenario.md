# 主线演示（01）—— 标准 / 复杂双场景

预计 5–6 分钟。

## 1. 开场：驾驶舱（30 秒）

操作：
- 浏览器打开 `http://localhost:3000/`。
- 点击右上角「进入驾驶舱」。

讲解：
- 展示「当前 Demo 项目 / 最近 Run」和「知识引用网格」。
- 说明所有 Run 均可在 `/workflow` 查看 10 步执行细节。

## 2. 演示模式开关（15 秒）

操作：
- 在 PageHeader 点击「演示模式」开关，深色主题切换。

讲解：
- 深色主题是商业会议首选；`prefers-reduced-motion` 已开启的同学会看到动画降级。

## 3. 标准场景（1 分 30 秒）

操作：
- 导航到 `/planner`，URL 自动补 `?preset=standard`。
- 选择「常规 · 露天台阶爆破」，逐字段输入（或直接点「应用预设」）。
- 表单字段：工程类型 / 岩石等级 / 含水条件 / 环境敏感 / 成本偏好 / 施工便利性 / 周边保护对象 / 自由备注。
- 点击「启动 Agent Workflow」。

讲解：
- Planner 在表格失去焦点时自动草稿；中途可随时取消。
- 6 步 Timeline 包括：参数标准化 → 规则预检 → Agent 推理 → RAG 检索 → 方案评分 → 报告生成。

预期：
- 12 个 Agent 状态依次走到 `succeeded`，Timeline 上一个绿色脉冲。
- 右侧「推荐 / 备选 / 风险」3 个方案卡显示分数与亮点。

## 4. 复杂场景（1 分 30 秒）

操作：
- URL 切到 `/planner?preset=complex`。
- 工程类型改为「underground-cavern」或「tunnel」；含水 = `wet`；环境敏感 = `medium`。
- 点击「启动 Agent Workflow」。

讲解：
- 装药结构会自动从 `coupled` 调整为 `decoupled`。
- 选中「推荐方案」→ 下方图表自动联动雷达 / 柱状 / 敏感性热力图。
- 点击任意引用（页面右下角），弹出 CitationPanel：含文档 / 章节 / 命中片段 / 检索得分 / 使用 Agent / 影响结论。

预期：
- 引用块至少 2 条，其中一条命中 KB-DOC-002（含水炮孔装药）。
- 敏感性热力图显示「最大单响 × 含水条件」红色高亮。

## 5. Workflow 可视化（45 秒）

操作：
- 导航到 `/workflow`。
- 切换到「最近 Run」。
- 点击任一节点（如 `agent.rule_precheck`）。

讲解：
- 10 节点环形布局，颜色区分状态。
- 节点详情面板显示：步骤输入 / 输出摘要 / 调用 Tool / 引用列表 / Trace 摘要。

预期：
- 引用面板同 Planner 一致。

## 6. 报告与导出（45 秒）

操作：
- 回到 `/planner`，点「生成报告」。
- 报告加载后跳转到 `/reports/<id>`。
- 点「打印 / PDF」→ 浏览器原生打印对话框 → 目标选择「另存为 PDF」。

讲解：
- 报告数据来自同一个 Planning Run；不会出现「重新随机生成」。
- 章节：封面 / 场景摘要 / 原始输入 / 标准化参数 / 方案对比 / 风险清单 / 知识引用 / Workflow 摘要 / 人工复核 / 安全责任边界。

预期：
- HTML 报告 A4 纸张适配，单列、字号 12pt。

## 7. 收尾（15 秒）

操作：
- 关闭浏览器 Tab，回到首页。

讲解：
- 切回下一页高风险场景（或现场答问）。

补充：
- 如果模型失败，Orchestrator 自动降级到 Replay；UX 没有任何「Loading」卡死。
